# 架构与目录

## 运行链路

工作台是 DSH 插件，浏览器请求先经过宿主本人身份验证，再进入固定操作白名单。组合监督器通过所属子进程 IPC 管理网关，通过已核验的本机接口管理桥接。页面不能提供任意后端地址或任意系统命令。

QQ消息从原生网关进入桥接。桥接根据会话范围与功能授权创建或继续 DSH 会话，把智能体的回复转为文字、图片、语音或其他已授权动作。发送结果按原生回执确认，不确定结果触发暂停与诊断。

电话拥有独立会话和音频进程。收到来电后，根据已有私聊身份映射检查权限，再建立识别、模型回复和合成声音的链路。挂断、超时和进程退出分别确认。

## 源码目录

| 目录 | 职责 |
| --- | --- |
| `qq-bridge-work/bridge/src/` | 桥接、会话、角色、记忆、工具、媒体及权限；TypeScript源码与运行用JS |
| `qq-bridge-work/bridge/plugins/qq-mode-console/` | 工作台布局、主题素材、固定RPC及宿主装配 |
| `qq-bridge-work/bridge/plugins/qq-agent-presets/` | 智能体预设与工具范围 |
| `qq-bridge-work/bridge/public/console-src/` | 既有桥接管理页面的源码；其管理接口仍被工作台复用 |
| `qq-bridge-work/integration/` | 服务监督、恢复、配置准备及资料管理适配 |
| `qq-bridge-work/native-research/native-adapter/` | 当前运行的原生网关、登录、账号会话、消息与媒体适配 |
| `qq-bridge-work/native-research/phone/` | 当前电话协议、NTRTC宿主源码与音频进程管理 |
| `qq-bridge-work/vendor/silk-wasm/` | 固定版本SILK编解码依赖，保留原许可证 |
| `installer/`、`deployment/` | 对应本机部署结构的安装与生命周期脚本源码 |

`native-research` 是沿用的目录名，其中部分源码属于实际运行链路。名称带 `candidate` 的宿主源码也可能被当前电话实现固定引用，不表示可以直接删除或替换。

## 数据与权限

运行数据位于本机部署目录，不属于源码仓库。角色、会话、登录态、模型配置、声音资源与代码更新分开保存。更新工作台使用固定公开文件白名单，不覆盖这些个人数据。

所有网页管理入口只面向本机本人。跨源请求、智能体身份调用管理动作、非法操作名和超长请求会被拒绝。登录二维码仅连接页按需读取，运行监控只返回允许显示的状态和计数。

资料管理的缓存仅限当前工作台内存；相同请求合并、不同会话分开缓存，保存后使相关缓存失效。运行监控每3秒重新检查，状态无法确认时显示未知。
